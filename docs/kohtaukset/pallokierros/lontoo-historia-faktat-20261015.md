## Pudotetut väitteet ja ongelmat

- Lähteet ristiriidassa, väite pois: Lontoon palon homeless-luku (70 000 / 100 000), tarkka kuolleiden määrä, kirkkojen tarkka luku (86/87/89 -> "yli 80"), palon viikonpäivä (vain Wikipedia), palon loppupäivä (5. vs 6.9. -> "noin neljä päivää").
- Suuren löyhkän lakiesityksen kesto: London Museum ja Historic UK "18 päivää", Wikipedia 15.6.-2.8.1858 eli 48 päivää -> pudotettu. Viemärien pituus 82 vs 83 mailia -> käytetty vain 1 100 mailin katuviemäriluku, jonka kaksi lähdettä (Wikipedia, Grace's Guide) antaa samoin. Pumppuasemat (Deptford, Abbey Mills) vain London Museumilta -> pudotettu.
- Trafalgar: brittilaivaston koko (27 vs Gazette 33) ja tappioluvut (17/18/19/22 alusta) ristiriidassa -> vain 17 antautui + 1 tuhoutui (RMG + Wikipedia) ja ei brittitappioita. "Tarkka-ampuja": lähteet sanovat musketööri/musketinluoti -> käytetty "luoti".
- Tuntematon sotilas: valintayö 7. vai 8.11.1920 (Abbey/Wikipedia-ero) -> päivä pois. Arkun miekka (Abbey: Towerin 1500-luvun miekka; Wikipedia: kuninkaan valitsema kokoelman miekka) -> pois. Nykyisen hautakiven paljastus 11.11.1921 vain Abbey -> pois.
- Buckinghamin palatsi: Elisabetin lause "I am glad we have been bombed..." sanamuoto vaihtelee (ensimmäinen kirjaus 1955 elämäkerrassa) -> pois. Pommien määrä (5 vs 6) ja loukkaantuneet henkilökunnan jäsenet -> pois. "Kuninkaalliset eivät olleet vahingoittuneet": toinen lähde (rct.uk-kirje) 403 -> pois. Galleria "Queen's Gallery" vs Wikipedian "King's Gallery" -> nimi pois, vain "galleria" ja vuosi 1962.
- Ruutisalaliitto: Monteaglen varoituskirje 26.10.1605 vain Wikipedia -> pois. Fawkesin valenimi John Johnson ja sytytyslaitteet vain National Archives -> pois. Parlamentin avajaisten päivämäärä (5.11.) vain Wikipedia -> pois. Teloituspäivät (30.-31.1.1606) vain yksi luotettava lähde -> "tammikuussa 1606".
- Kruunuvarkaus: mikä kruunu (Wikipedia Imperial State Crown, HistoryHit St Edward's) -> vain "kruunu". Valtikan sahaus ja Edwardsin vammat (puukotus) vaihtelevat lähteittäin -> pois. Edwardsin perheen palkkio (n. 300 puntaa, ei täysin maksettu) jätetty tilan vuoksi pois (Wikipedia + HistoryHit tukevat, varavalinta).
- Harrison: H4:n virhe pituuspiirinä (Lindahl noin 2 mailia, Wikipedia noin 1 meripeninkulma) ristiriidassa -> vain sekunnit. Jamaikan matkan kesto (81 päivää vain Wikipedia) -> pois. Harrisonin kellojen sijainti Greenwichissä pois (aikasidonnainen, ei vuotta).
- Ongelmat: ei kuvia tässä erässä (ei pyydetty). Riippumaton tarkistus tekemättä.
