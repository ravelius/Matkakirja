# Odessan nähtävyysminiatyyrien tyyliaudit (27.9.2026)

Odessan kaikki seitsemän karttaminia luettiin julkisista R2-osoitteista ja tarkistettiin koko kaupungin [ennen/jälkeen-kontaktiarkissa](kuvat/odessa-miniatyyrit-ennen-jalkeen-20260927.jpg). Nykyiset kuvat ovat yksittäisiä, rajattuja muste-vesiväridioraamoja viistosta ylhäältä. Sävyinä ovat hillityt beige, seepia ja oliivi. Kuvissa ei ole horisonttia tai tarinakohtausta, joten kaikki säilyvät ennallaan.

Kaksi viimeksi mainittua porraskuvaa kuvaa samaa nähtävyyttä eri tunnisteilla. Tämä on sisältöluettelon mahdollinen kaksoiskappale, jonka Fable voi ratkaista; kumpaakaan kuvaa ei muutettu tässä tyyliauditissa.

Jokainen julkinen GET palautti HTTP 200, PNG-MIME:n ja pelin originille CORS-luvan. Kaikissa on sRGB-ICC, aito alfa ja neljä täysin läpinäkyvää kulmaa; näkyvä siluetti ei osu reunaan. Tarkat SHA-256-, täyttö- ja reunamittaukset sekä alkuperäisten R2-tiedostojen kopiot säilyvät työtilan `output/style-audit-europe-20260927/odessa/`-kansiossa. Uusia kuvia, R2-objekteja tai pelin kuvalinkkien muutoksia ei tehty.
