## 2) ISS Cupola 3: PASS
`linssi satelliitti` → `astro kyyti` → `astro kyyti nopeus 100/1000` ikkunatilaan. Kupoli pyöreä,
metallikehys opaakki sekä päivällä (kirkas pilvinen näkymä) että yöllä — ei havaittavaa läpikuultoa
maasta tai pulusta kehyksen läpi kummassakaan. Ohjaamotekstuuri `iss-cupola3-a-pehmea-umpi-iphone`.
Kuvat: docs/raportit/kuvat/cupola3-paiva-20260929.png, docs/raportit/kuvat/cupola3-yo-20260929.png.

## 3) Maakuntakortti: PASS
`uusi-peli 1 ateena` → maakuntakartta päälle (☰-kuvake) → napautus Thessaliaan: kortti on
nostokortin kokoinen (THESSALIA-otsikko, pieni kuva, kuvausteksti). Kuvan napautus avasi
täysin kokoruutuun laajennetun "Thessalia"-kortin (iso kuva, koko teksti, Pulu-kysymykset).
Sulkemisen jälkeen saman maakunnan uusi napautus poisti valintatilan täysin (normaalit
nostomerkit palasivat, ei jäänyttä maakuntakartta-tilaa).

## 4) Mallien nimiöt (Visby, Český Krumlov): PASS
Natiivi-UI:n cl16-kaavalla (uusi peli Roomaan, symbolit loydetty/maalla/seepia, `nostot maa
SWE`/`CZE`, `nostot kerroin <k> <lat> <lon> 1.0`, komento.txt-rivit peräkkäin):
- Visby: lokirivi `kohde:visby#1 oikea näkyy ... elOpa 1,00` — nimiö "Visby" näkyy mallin
  oikealla puolella kuvassa. Kuva: docs/raportit/kuvat/nimio-visby-20260929.png.
- Český Krumlov: lokirivi `kohde:cesky-krumlov#2 yla näkyy ... elOpa 1,00` — nimiö
  "Český Krumlov" näkyy mallin yläpuolella. Kuva: docs/raportit/kuvat/nimio-krumlov-20260929.png.

Molemmat täsmäävät Natiivi-UI:n odottamaan lokimuotoon tarkalleen.
