# Olavinlinna: repliikkien sukupuoli- ja englanninnettavuustarkistus (7.10.2026)

Sisältökirjuri (Sonnet 5.5, high). Tarkistettu: 31 manifestirepliikkiä (`olavinlinna-pystyleike-repliikit.md`), v3-kohtausten keskustelut (`kohtaukset-v3.js`: laituri, keittiö, keskushalli, kappeli, fatabuuri, muurinharja, kierreportaat) ja kappelin E3-käsikirjoitus (`kasikirjoitus-olavinlinna-kappeli-e3.md`). Sääntö: pelaaja puhuteltu "sinä", sukupuoleton; englanniksi **Fogg / you / they, ei he/she** (Raamattu, käännösohje).

## 1. Sukupuolitarkistus: tulos

**Suomenkieliseen tekstiin ei tarvita muutoksia.** Yksikään pelin aikana soiva repliikki tai kohtaus ei viittaa Fogg tai Pulu sukupuolitetusti; suomen "hän" on neutraali, eikä Foggista puhuta kolmannessa persoonassa ääneen (vain käsikirjoitusproosassa nimellä "Fogg"). Puhuttelut Foggille ovat sukupuolettomia:

| Repliikki | Sana | Arvio |
|---|---|---|
| portinvartija-tarttuu-4 | "pikku vintiö" | sukupuoleton; säilyy (Päätoimittajan linjaus); en: "little scamp/rascal" |
| vartija-valpas-1 | "pikku rotta" | sukupuoleton; en: "little rat" |
| kokki-halytys-6 | "varas" | sukupuoleton; en: "thief" (ei "burglar/thief he") |
| vartija-kiinni-1/-2 | "Seis!", "Kellariin siitä… mitä sinusta tehdään" | sukupuoleton |
| portinvartija-epaily-3, kokki-epaily-5 | "Kuka siellä?", "Kuka siellä hiippailee?" | sukupuoleton |

Muut sukupuoliset sanat ovat **toisten hahmojen kanoonista sukupuolta**, eivät pelaajaa: "Herra vouti", "herra kirjuri", "isä" (kappalainen), "vesipoika", "isoisä" (rengin isoisä, ei Foggin), patronyymit tietokerroksessa (Erik Akselinpoika Tott, Pietari Niilonpoika Kylliäinen). Näihin ei kosketa.

**Englanninnoksen vaaranpaikat (ei suomessa):** (1) älä kirjoita "he/she" Foggista missään kohtauskuvauksessa, alt-tekstissä, tietokerroksen kortissa tai vihjeessä: käytä "Fogg" tai "you" ja kertoessa "they"; (2) hahmoetiketit: "soutaja" → "rower/ferryman" (ei "boatsman"), "talonpoika" → "farmer"/"peasant", "vartija" → "guard", "apulainen" → "helper" — sukupuoli vain nimikkeissä, joissa kanoni on selvä (vouti = "the bailiff", kappalainen = "the chaplain", "Father"); (3) kappalainen-1, -3 ja v3 ovat valmiiksi miehisiä (äänet), joten "Father" / "Sir Bailiff" sopii.

## 2. Englanninnettavuus: huomiot ja suositukset

Sanamäärät (1–12) pysyvät englanniksi samassa haarukassa kun käytetään supistuksia. Äänen ohjeet ja ajoitus: v3-kohtausten vuorot ovat sekunteja WAV-masterista, joten **englanninkieliset vuorot generoidaan ja ajoitetaan uudelleen** (kesto muuttuu); kappeli-E3:n ajastuksessa (voudin lähtö 2 s viimeisen vuoron jälkeen) käytetään uusia kestoja.

| Kohta | Haaste | Suositus (en) |
|---|---|---|
| soutaja-1 "Aarnivalkea… Herra meitä varjelkoon." | aarnivalkea = aarteen paikkaa merkitsevä liekki; ei englanninkielistä vastinetta | "Treasure-fire… Lord, protect us." (hahmo selittää tietokerroksessa: "aarnivalkea, a will-o'-the-wisp said to mark buried treasure") |
| soutaja-2 "Kalalasti tulee! … ennen kuin kalat alkaa haista!" | kalalasti = lastillinen kalaa | "Fish cargo coming in! Open up before the catch starts to stink!" |
| portinvartija-tarttuu-4 | "pikku vintiö" | "little scamp" |
| portinvartija-paluu-5 | "kanna jo ne kalasi sisään" | "carry those fish of yours inside already" |
| kokki-epaily-3 "tornin tarjotin" | "tornin" = tornin vartijan tarjotin; ilman kontekstia epäselvä | "Where did the tower's tray get to?" → mieluummin "the tower guard's tray" |
| kokki-paluu-4 "Kala ei keitä itseään." | sananparsi | "The fish won't cook itself." |
| vartija-paluu-1 "Kissa kai." | puhekielinen ellipsi | "Must've been a cat." |
| vartija-paluu-2 "…voudin hermot tarttuu minuunkin." | sanaleikki voudin hermostumisesta | "The bailiff's nerves must be catching." |
| vartija-valpas-1 "pikku rotta juoksee linnassa" | ok | "Eyes open! Some little rat is running loose in the castle." |
| v3 laituri "kavassi" | ei tunneta englanniksi | "great vessels"/"big hulls" (kertojarivi, ei soi pelin aikana; selitys tietokerrokseen) |
| v3 keskushalli "Kolme kuutosta! Maksa…" | noppapeli | "Three sixes! Pay up, if you dare." |
| v3 keskushalli "päätön kana" | idiomi toimii | "like a headless chicken" |
| v3 fatabuuri "fatabuuri", "verkaröijyä" | ruotsalaisperäinen aitta; verka = karkea villakangas, röijy = takki | "storeroom/wardrobe store"; "two wool jackets" |
| v3 muurinharja "tuhatneljäsataayhdeksänkymmentäviisi" | luku sanoina ääntämisen vuoksi | "fourteen ninety-five" |
| kappalainen-1, v3 kappeli "Dominus vobiscum…", "In manus tuas, Domine…" | latina säilyy; käännöksessä alku on latinaa (poikkeus ensimmäisen sanan säännöstä, kuten suomessakin) | säilytä latina; "Herra vouti" → "Sir Bailiff" (tai "My lord Bailiff") |
| v3 kappeli "tuon pienen aukon takana sairaat odottavat" | hagioskooppi (leper's squint) | "behind that little opening, the sick wait to see the altar" |
| vesipoika-1 ja v3 keittiö: "mua", "palanu", "itekin", "tää", "mä" | murteellinen/puhekielinen rekisteri | käytä englannin puhekielen supistuksia ("ain't"/"gonna" vain jos hahmo sopii), ei amerikkalaista slangia; vesipoika "Water boy" (kanoni) |

Muuta: (a) ensimmäinen sana englanniksi englantia (puhesynteesi), latina vain kappalaisella; (b) repliikit ovat edelleen 1–12 sanaa; (c) pitkät lauseet (v3 kokki 1) venyvät englanniksi — jaa kahteen virkkeeseen tarvittaessa; (d) tarkista äänet (ElevenLabs en-hahmot) erikseen; (e) tietokerroksen faktat eivät kuulu tähän tarkistukseen.
