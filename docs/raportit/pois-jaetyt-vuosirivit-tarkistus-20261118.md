## Huomiot KK:lle
1. **Ainoa varsinainen virhe: Saint-Eustache 1655 → 1665.** Muut ovat pehmennyksiä tai jäävät.
2. **Äänitteet**: en tarkistanut onko tekstit äänitetty (jonon avaimet ovat tiivisteitä); jos on, muutos = uusi äänitys. Pompidou ja Saint-Eustache 1649 eivät muutu.
3. **Ei tehty**: yhdenkään tekstin muutosta ei ole tehty; odotan KK:n sanaa (korjataan / pehmennetään / jää).
4. Lähteiden heikkous: suurin osa tuesta on fr-WP ja en-WP sekä hakutulos. Jos KK haluaa kolmannen lähteen (Mérimée / CMN / Britannica), pyydä erikseen.
