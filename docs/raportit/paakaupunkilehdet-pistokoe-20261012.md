# Euroopan 14 pääkaupunkilehden loppupistokoe (Sisältökirjuri 12.10.2026)

PT:n tilaus (junan 182 pääkaupunkilehdet, #4386): jokaisesta 14 lehdestä (Belgrad, Bratislava, Chișinău, Minsk, Podgorica, Skopje, Tirana, Zagreb, Andorra la Vella, Bern, Monaco, Reykjavík, San Marino, Vaduz) 3–6 tarkinta väitettä (luvut, vuosiluvut, väkiluvut, "ensimmäinen/suurin") tarkistettiin vähintään kahdesta riippumattomasta lähteestä (5 Sonnet-tarkistajaa; lähteet liitteessä). Pelkät lehdet ja nähtävyysjutut; ei generointia, vain Eurooppa.
