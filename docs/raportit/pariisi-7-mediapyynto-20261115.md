# Mediapyyntö PT:lle: Pariisin 7 kadonneen tarinapaikan kuvat (SK 15.11.2026)

Data-luonnos (haara sk/pariisi-7-data) viittaa seitsemään Commons-kuvaan `NAHTAVYYSJUTUT.pariisi[…].kuvat[0].tiedosto`-kentässä
(js/packs/nahtavyysjutut.js). Yksikään ei ole vielä pelin mediassa (tools/vienti/kuvamitat.json), joten PR jää luonnokseksi,
kunnes kuvat on viety mediaan. Kuvia EI ladattu peliin. Lisenssit luettiin kunkin /wiki/File:-sivun Licensing-osiosta 15.11.2026
(User-Agent MatkakirjaResearch/1.0) ja kuvat katsottiin silmin (Special:FilePath-esikatselu).

Kaikki kuvat ovat CC0- tai PD-aineistoa (pysyvä latauslupa, kortti lisenssit-ja-lataukset sääntö 1). Kenttä: `kuvat[0].tiedosto`
(+ `lyhyt`, `selite`, `lahde` valmiina datassa). Miksi: jokaiselle jutulle yksi aito aikalaiskuva kadonneesta rakennuksesta;
ihmekuva (hahmotelma) tulee jutun ensimmäiseksi kuvaksi automaattisesti nimellä, tämä on toinen kuva karusellissa.
