Kortti: taiteilijan pieni muotokuva + teoksen lyhyt (1–2 faktaa, yhteensä ≤ 160 merkkiä). Muut tiedot (nimi, tekijä, vuosi, tekniikka, koko, museo) ovat jo teokset.json:ssa.

## Tiedostot

- docs/kohtaukset/museoteokset/lyhyt-ranska.json: 44 / 51 teosta.
- docs/kohtaukset/museoteokset/taiteilijat.json: avain = teokset.json:n "tekija" täsmälleen; 41 kuvallista, 14 null (syyt: ei-kuvaa-syyt.json).
- docs/kohtaukset/museoteokset/kuvat/*.jpg: 39 muotokuvaa, 256×256, kasvot keskellä. Kaikki PD tai CC0 (Commons-lisenssi tarkistettu API:lla 16.10.), tunnus + lähde taiteilijat.json:ssa.
- Menetelmä: docs/kohtaukset/museoteokset/tyokalut/ohje-agentille.txt (Sonnet-agentit, kaksi lähdettä per fakta).
