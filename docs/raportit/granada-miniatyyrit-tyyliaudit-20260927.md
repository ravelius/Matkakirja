# Granadan nähtävyysminiatyyrien tyyliaudit (27.9.2026)

Granadan kaikki yhdeksän karttaminia luettiin julkisista R2-osoitteista ja tarkistettiin koko kaupungin [ennen/jälkeen-kontaktiarkissa](kuvat/granada-miniatyyrit-ennen-jalkeen-20260927.jpg). Nykyiset kuvat ovat rajattuja, viistosta ylhäältä kuvattuja muste-vesiväridioraamoja hillityin beigein, seepian ja oliivin sävyin. Niissä ei ole horisonttia eikä tarinakohtausta. Kaikki kuvat säilyvät ennallaan.
