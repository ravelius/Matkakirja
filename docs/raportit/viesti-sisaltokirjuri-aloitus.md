# Sisältökirjurin aloitusviesti (päivitetty 5.10.2026)

Lue ensin `docs/raportit/viesti-sisaltokirjuri-luovutus-20261005.md`: erät 1–4 mainissa (226 kohdetta), erä 5 kesken.

Työtapa:
- Vain Eurooppa uudelle satelliittisisällölle. Kuvat NASAn ISS-kuvista (images-api tai Gateway).
- Jokainen kuva katsotaan silmämääräisesti ja ajetaan `tools/astro-palkki.mjs tarkista`. Tunnuspalkilliset rajataan (`rajaa`) ennen vientiä.
- Duplikaattitarkistus: sama nasa_id ja lat/lon alle 0.5° jo listalla → ei lisätä.
- PR vasta kun ≥ 8 kohdetta on ilman ämpäriä tai omistaja on antanut ämpärilupan.
- Ei pushata haaraan junan aikana.

Avoin: ämpärilupa erälle 5 (6 rajattua kuvaa, polku ylempänä).
