# Livian pulu — Portugalin 20 aluetta, luonnos (Sisältökirjuri, 27.9.2026)

Kaksi kysymys–vastaus-paria per alue, EI päällekkäisiä "lyhyt"-faktan kanssa.
Faktat tarkistettu WebSearchilla (lähteet mainittu kunkin alueen kohdalla),
ei keksittyjä lukuja. Valmiit JS-katkelmat suoraan liitettäviksi.

Luottamustaso: KORKEA = tarkistettu hakukoneella, tarkka luku/vuosi löytyi.
KESKI = yleistunnettu, laajasti dokumentoitu, ei kriittistä täsmälukua.
