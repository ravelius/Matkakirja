# Saapumisintron rivit: Lappi (id lappi, aluekokonaisuus), haettu 12.11.2026

Säännöt: KK:n päätökset 11.11.2026 (sääntö 1–12). Kaikki kahdeksan kuvaa ladattu ja katsottu (sips -Z 1000). Ei yhtään "EI KATSOTTU" eikä "VÄÄRÄ KAUPUNKI" -riviä.

Merkinnät: KOHDE PÄÄTELTY = kuvassa ei ole kylttiä, joka vahvistaisi paikan; kohde päätelty tiedostonimestä ja kuvatekstistä, ja kuva sopii siihen. Kyläkuvissa (4, 7) kuvasta ei voi tunnistaa tarkkaa kylää tai paikkaa. Ei-rakennuksilla lähteitä ei tarvita.
Lähteiden saatavuus: fi.wikipedia.org ja en.wikipedia.org aukesivat; Arktikumin oma historiasivu (arcticcentre.org) ei aukea suoraan, tieto sivun sisällöstä on hakutuloksesta; Structurae antoi 403 suoraan, sen sisältö hakutuloksen tiivistelmästä.
