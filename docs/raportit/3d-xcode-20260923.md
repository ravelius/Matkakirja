# Xcode Unity 6.3 + Cesium -prototyyppiä varten (23.9.2026)

Tekijä: 3D-selvittäjä (Opus 5.5). Tilaaja: Fable. Taustalla omistajan moottoripäätös
Unity 6.3 LTS + Cesium for Unity. Tässä ei asennettu mitään eikä ajettu sudoa; koneelta
ajettiin vain lukukomentoja.

## Tiivistelmä

- **a)** Unity 6.3 ei vaadi Xcode 27:ää. Unityn vähimmäisvaatimus on Xcode 16. App Storeen
  vaaditaan Xcode 26 ja iOS 26 SDK (28.4.2026 alkaen). Xcode 26.x riittää siis, ja Xcode 27
  kelpaa myös.
- **b)** Xcode 27 toimii macOS 26:lla. Applen mukaan vähimmäisversio on macOS Tahoe 26.6
  (Apple silicon). Kone on macOS 26.6.2, ja Xcode 27.0 on jo asennettu ja toimii.
  macOS 27 -päivitystä ei tarvita.
- **c)** Koneella on yksi Xcode: **/Applications/Xcode.app = Xcode 27.0 (27A266a)**. Se on
  jo valittuna ja käyttökunnossa käyttäjälle koodaus. Siitä puuttuvat vain **Metal
  Toolchain -komponentti** sekä **Apple ID ja allekirjoitusidentiteetti** laitetta ja
  TestFlightia varten.
- Suositus: käytetään Xcode 27.0:aa. Xcode 26.x:n asentaminen rinnalle ei ole tarpeen.
  Jos Unity 6.3 ei rakennu Xcode 27:llä, varavaihtoehto on Xcode 26.6 (vaatii macOS 26.2+,
  kone täyttää ehdon). Se asennetaan erilliseksi sovellukseksi, esim. /Applications/Xcode-26.6.app.

## a) Unity 6.3:n Xcode-vaatimus

- Unity 6.3:n manuaali (System requirements ja iOS requirements) sanoo iOS-buildista
  "Xcode version 16 or later". Tuettu iOS on 15+.
- Apple vaatii 28.4.2026 alkaen, että App Store Connectiin ladattavat sovellukset
  rakennetaan Xcode 26:lla tai uudemmalla iOS 26 SDK:ta vasten. Xcode 27 ja iOS 27 SDK
  täyttävät vaatimuksen.
- Unity ei ole vielä julkaissut virallista tukilausuntoa Xcode 27:lle; Xcode 27 julkaistiin
  14.9.2026. Unity Build Automationin uusin Xcode on 26.5. Uusi Xcode toimii yleensä, mutta
  ensimmäisillä viikoilla on esiintynyt vikoja. Esimerkkejä Xcode 26:n ajalta:
  - Metal Toolchain 26.0 -asennuksen jälkeen IL2CPP-linkitys kaatui ("Command Ld failed").
    Kiertotie on GameAssembly-kohteen Build Phase -skriptissä: SELECT_TOOLCHAIN_SDK_AUTOMATICALLY=true
    tai DT_TOOLCHAIN_DIR TOOLCHAIN_DIR:n sijaan.
  - Xcode 26.0.1:n linkkerissä oli AR-projekteja koskeva assert (dylibToOrdinal).
- Xcode 27:n tunnetuista rikkoutumista Unityyn voi osua linkkerilippu: -ld64 ei enää toimi, ja
  -ld_classic antaa vain varoituksen. Unity 6.3:n generoimaa projektia ei ole vielä tarkistettu tämän osalta,
  mutta asia **tarkistetaan ensimmäisessä buildissa**.
- Laitedebuggaus vaatii Xcode 27:llä, että laitteessa on iOS 17+. iPhone 13–16 täyttää ehdon.
- Cesium for Unity tukee iOS:ää, mutta ei ilmoita omaa Xcode-vaatimusta. Siitä on korjattu
  iOS-linkkausvika (Blend2D, v1.17, syyskuu 2025). Käytetään uusinta versiota.

## b) Xcode 27 ja macOS 26

Applen järjestelmävaatimussivun mukaan:

| Xcode | Vähimmäis-macOS |
|---|---|
| 27.0 ja 27.1/27.2 beta | macOS Tahoe 26.6 |
| 26.4.1–26.6 | macOS Tahoe 26.2 |
| 26.0–26.3 | macOS Sequoia 15.6 |

Kone on macOS 26.6.2 (25G83), joten Xcode 27.x toimii ilman macOS 27:ää. Myös 27.1 käy,
kun se julkaistaan. Tämä on todennettu koneella: `xcodebuild -version` → Xcode 27.0,
kaikki 27-SDK:t näkyvät, ja iOS 27.0 -simulaattoriajoaika on asennettu.

## c) Koneen Xcode ja käyttöönotto käyttäjälle koodaus

Mitattu 23.9.2026 käyttäjänä koodaus. Käyttäjä on admin- ja _developer-ryhmissä.

| Kohde | Tila |
|---|---|
| /Applications/Xcode*.app | vain Xcode.app, 27.0 (27A266a), asennettu 17.9. |
| `xcode-select -p` | /Applications/Xcode.app/Contents/Developer ✔ |
| `xcodebuild -license check` | hyväksytty ✔ |
| `xcodebuild -checkFirstLaunchStatus` | valmis ✔ (ensikäynnistyksen paketit asennettu) |
| SDK:t | iOS 27.0, iOS Simulator 27.0 ✔ |
| Simulaattoriajoaika | iOS 27.0 (24A434), 5 iPhone-laitetta ✔ |
| Metal Toolchain | **uninstalled** ✘ (`xcrun metal` → "missing Metal Toolchain") |
| Allekirjoitusidentiteetit | **0** ✘ (`security find-identity -v -p codesigning`) |
| Xcoden Apple ID -tili | **ei ole** ✘ (Xcodea ei ole avattu käyttöliittymänä koodaus-käyttäjänä) |
| Vapaa levytila | 94 Gt |

Xcoden valinta, lisenssi ja ensikäynnistys ovat siis valmiit. Uutta asennusta,
xcode-selectiä tai sudoa ei tarvita.

## Mitä omistajan pitää tehdä (käyttäjänä koodaus)

1. **Metal Toolchain.** Avaa Xcode → Settings → Components → Other Components → Metal
   Toolchain → Get. Päätteessä vastaava komento on `xcodebuild -downloadComponent MetalToolchain`
   (ei sudoa). Unity kääntää shaderinsa itse, mutta Xcode-projektin buildi
   voi tarvita komponenttia. Applen tunnetun vian (FB20389216) mukaan komponentti ei
   välttämättä näy muille Macin käyttäjille, joten se asennetaan **nimenomaan
   koodaus-käyttäjänä**. Vaihtoehtoisesti sen voi jättää ensimmäiseen buildiin ja asentaa
   vasta, jos buildi valittaa. Asennuksen jälkeen tarkista, ettei IL2CPP-linkitysvika
   (yllä) toistu.
2. **Apple ID Xcodeen.** Xcode → Settings → Accounts → + → Apple ID. Kirjautuminen on
   omistajan tehtävä, agentti ei syötä tunnuksia. Tämän jälkeen Xcode luo automaattisesti
   Apple Development -sertifikaatin, kun Signing & Capabilities -kohdassa valitaan tiimi.
3. **Apple Developer Program** (99 $/v) tarvitaan TestFlightiin ja App Storeen.
   Ilmaisella Apple ID:llä saa asentaa omaan iPhoneen, mutta allekirjoitus vanhenee
   7 päivässä. Simulaattori ei vaadi kumpaakaan.
4. **iPhone kehittäjätilaan**, kun laitetestaus alkaa: Asetukset → Tietosuoja ja
   turvallisuus → Kehittäjätila. Laite liitetään kerran kaapelilla ja valitaan "Luota".

Kohdat 2–4 eivät estä prototyypin simulaattorivaihetta. Unity-editorin ja
Cesium-paketin asennus on erillinen päätös (Unity Hub, Unity-tili).
