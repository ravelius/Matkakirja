Koneluettava: `kuvatekstikorjaukset-era3-ehdotus-20261112.json` (kentät kuten erissä 1–2: kaupunki, nro, tiedosto, luokka, vika, nyt_lyhyt, nyt_selite, lyhyt, selite; `lyhyt`/`selite` = ehdotus). **63 ehdotusta**: A = väärä fakta tai kuva ≠ teksti, B = lähteetön/liioiteltu väite, C = tarkennus. Perusta: `saapumisintro-era3-tutkimus/tulos-*.md` (osio "Kuvatekstien virheet") ja KK:n introrivipäätökset 12.11. klo 09.12.
