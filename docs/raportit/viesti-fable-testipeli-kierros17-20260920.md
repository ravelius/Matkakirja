# Testipeli, kierros 17 — osaraportti v1970 (20.9.2026 klo 1.50–2.28)

Laite: iPhone-simulaattori (390 px), tuotanto v1970 (ladattu "PELI PÄIVITTYI" -dialogista 1.51),
maailma-kytkin päällä hyppyihin (pois kierroksen lopuksi), äänet pois.
Kaappaukset: `docs/raportit/kaappaukset/kierros17-20260920/`. Simulaattori-ohjaus oli
välillä rate-limitattu (osa tapeista toistettu); ei vaikutusta havaintoihin.

**Aika-huomautus:** v1971 tuli tuotantoon kesken kierroksen; tämä osaraportti kattaa v1970:n.
Loput (tekstinvalinta, ISS, Košice, v1971:n lisäkohdat) ajetaan v1971:llä.
