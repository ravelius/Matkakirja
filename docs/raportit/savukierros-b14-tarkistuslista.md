# Savukierros build 14: lisäkohdat (Pelikoodari Fablen pyynnöstä, 25.9.2026)

Aja kun käännösvahti ilmoittaa build 14 -testikäännöksen (ei ennen).

1. **Löydös 109 (aloitus):** kylmä käynnistys → aloitusportti → avausteksti →
   VALITSE ALOITUSKAUPUNKI → napauta Ateenaa KARTALTA (ei komentoa) →
   aloituslento → perillä. Ennen Liiku-napin painamista kartalla EI saa näkyä
   katkoviivareittejä eikä onttoja välipisteympyröitä. Liiku → reittiviuhka
   näkyy; saapumisen jälkeen reitit häviävät. Kuvat: ennen Liikua, Liikun
   jälkeen, saapumisen jälkeen.
2. **Löydös 100:** kartun (maakyltin) radionappi → valo punaiseksi JA radio
   kuuluu (kaiuttimet päällä; mittaa `radio tila`/rms, ei vain kuvaa).
3. Samalla katsottavaksi: **93** (karttanosto aukeaa myös nimiöstä) ja
   **104** (nostokortti aukeaa heti).

Muistiinpano: iPad 3B4CDACB / iPhone 1572C658 sammuksissa, sammuta kierroksen jälkeen.
