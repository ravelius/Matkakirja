## Kooste muutoksista
1. bryssel.kysymys.fakta: "Pörssitalo valmistui 1873" -> "Pörssitalo vihittiin käyttöön 27. joulukuuta 1873."
2. bryssel.henkilo: "kunnostaa" -> "huoltaa" (restaurointi päättyi 2023).
3. kosice.kysymys: oikea vaihtoehto ja fakta tarkennetaan "vanhin säilynyt vaakunakirja" -muotoon (väite "ensimmäinen" on yleinen mutta Kassan oma arkistonhoitaja rajaa sen); vaihtoehto 3 (Unkarin kuninkaan henkilökohtainen vaakuna) korvataan selvästi väärällä.
4. ljubljana.henkilo: "Kolmoissillan torilla" -> "Keskustorilla Ljubljanica-joen rannalla".
5. ljubljana.kysymys.fakta: "linnan tornissa" -> "vaakunassa linnan tornin päällä".

- KORJATTAVA: Valletta, saapuminen "palanut kesällä" (palo oli 25.5.1873 eli toukokuussa/keväällä).
- KORJATTAVA: Valletta, fakta "paloi 1873; pommitukset tuhosivat jäänteet 1942" (talo korjattiin ja avattiin uudelleen 11.10.1877; 1942 pommitus osui toimivaan, korjattuun taloon; loput purettiin 1950-luvun lopulla).
