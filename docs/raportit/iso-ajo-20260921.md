# Iso ajo — eteneminen (aloitettu 2026-09-21)

Omistajan lupa: iso ajo alkaa. Fablen antama järjestys, yksi erä =
yksi haara, Fablelle 8 riviä per erä, kuvat ämpäriin vasta Fablen
pistokokeen jälkeen (3 nostoa + 3 kuvaa per maa).

## Vaiheet

1. **Kuvattomat (198)** — Commons ensin maittain suurimmasta (FRA,
   GRC, TUR, DEU, HRV, …); joille kuvaa ei löydy → Codex-lista.
2. **FRA:n 90 noston paketti standardiin** — tyypit, 38 "muut" oikeisiin
   tyyppeihin, 18 kartuschasta lainaavaa omalle tekstille, visat 1/3:aan.
3. **BEL/SVK/SVN/CYP 40:een, MLT 15:een.**
4. **Muu Eurooppa 30:een** maa kerrallaan: GBR, NOR, CHE, ISL, UKR,
   RUS, TUR, BIH.
5. **Visat ≥ 1/3 joka maassa** (8 maata ilman visaa ensin).
6. **Taso 3 -luokittelu kaikkiin maihin** + nimistö 1873 (aika-kenttä)
   ja tasot muille Euroopan maille FRA:n kaavalla.
7. **1–3 kadonnutta kohdetta (ihme) per maa lisää**, Codex-listalle.

## Huomio lukumääristä (2026-09-21)

Oma `tools/nostoinventaario.mjs`-työkalu näytti FRA:lle "Ilman kuvaa: 20",
mutta suora läpikäynti kanonisista exporteista (maastokohteet-fra.js +
hahmotelma-fra.js + fokuskohteet-fra.js) löysi **46** todellista
kuvatonta nostoa, mukaan lukien useita taso 1 -kohteita kuten
Mont-Saint-Michel, Carcassonne, Lascaux, Pont du Gard, Chambord ja
Étretat — työkalun laskuri aliarvioi (tarkistettu käsin usean kohdalla:
ei kuva- eikä tiedosto-kenttää lainkaan, mutta laskuri ei tunnistanut
niitä kuvattomiksi). Fablen luku FRA 39 on lähempänä 46:ta kuin 20:tä —
käytän 46:n listaa oikeana tässä erässä ja korjaan
`nostoinventaario.mjs`:n laskurin erikseen. GRC/TUR/DEU/HRV lukuja ei
vielä tarkistettu käsin.
