# noston-kuvat · vastuu NUI · tarkistettu 18.11.2026

TAVOITE: Noston kuvat ovat oikeita, kerronnan mukana tulevia ja oikeassa paikassa; kartalla kuvan päällä näkyy vain kohde.

SÄÄNNÖT:
1. Nostolla oikeita kuvia, kerronnan aikana kaikissa [P-261117-119]; havainnekuva vain kadonneen pääkuvana, rappeutuneen parina tai selvänä lisänä. [R-2.146] [R-11.16]
2. Eläinkohteen kuvassa eläin lähikuvassa, tarvittaessa muualta. [R-11.18]
3. Noston kuvat kartalla kohteen yläpuolella ja takana (kohde alhaalla); palkissa ei pikkukuvaa, vaakassa keskellä. [P-261117-123] [P-261118-14]
4. Kuvan päällä näkyy ainoastaan kohderakennus, ei muita rakennuksia eikä muuta. [P-261118-24]
