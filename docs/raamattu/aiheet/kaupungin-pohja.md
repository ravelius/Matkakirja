# kaupungin-pohja · vastuu KS · tarkistettu 18.11.2026

TAVOITE: Kaupungin pohjakartta on rauhallinen ja yhtenäinen: katot, asfaltti ja vesi eivät muutu häiritsevästi zoomattaessa eikä väriraja jää lähitalojen reunaan.

SÄÄNNÖT:
1. Kaukaisille 2D-taloille sama kattoväri maan tasalla kaikkiin paloihin yhtä aikaa, ei rajaa lähitalojen reunassa. [P-261118-21]
2. Lähivedessä ei näy raitoja. Asfaltti piirtyy myös kauempaa, jotta pohja ei muutu häiritsevästi zoomattaessa. [P-261118-22]
3. Kaupungin kattoväri näkyy jo kauimmassa kuvassa: asutusalue ja kaupungin massa kattosävyyn vain kaukotasoilla, häipyy rakennusten tullessa esiin. [P-261115-22]
4. Piirretyn kartan saanut kaupunki näytetään sillä kokonaan, noin 2,5 m/px, yksinkertaistettuna isoisän ajan matkailijan karttana. [R-2.204] [P-261102-2]
5. Lähikartat ajetaan kaikille kaupunkitaulun kaupungeille ja viedään ämpäriin; koneelle ne eivät jää. [P-261120-19]
