# Bergen – huomiot tarkistajalle

- Tarkistin: 0 virhettä. Kaikki "ei ala paikan nimellä" -huomiot johtuvat LISÄSÄÄNNÖSTÄ A (alku suomeksi: "Bergenin vanha laituri, Bryggen", "Kaupunkivuori Fløyen", "Köysirata Fløibanen", "Sauvakirkko … Fantoftin", "Säveltäjä Edvard Griegin koti Troldhaugen", "Konserttitalo Grieghallen", "Bergenin korkein kaupunkivuori, Ulriken", "Uusi kirkko, Nykirken", Bergenhus: "Vågen-lahden suulla, Bergenhusin linnakkeen…").
- Isoisä: vain Bergenin tuomiokirkko (tykinkuula, laivasto, lyijykynä). Kaanonissa opas "katsoi minua, sitten kuulaa" – jätetty pois, lyhennetty muotoon "mainitsi palvelleensa laivastossa, mutta vakuutti, että mukana oli vain lyijykynä".
- Lähteet: WebFetch oli estetty, kaikki tarkistettu WebSearch-otteista. Osa väitteistä nojaa pelin aineistoon (url "kaanon:pelin-aineisto"): Haakonin salin tehtävän unohtuminen ja tunnistus 1840, Fløibanenin mitat, Mariankirkko Bryggenin alueen korkein rakennus.
- korkeus_m jätetty pois kirkoilta (Mariankirkko, tuomiokirkko, Fantoft, Nykirken), koska tornikorkeuksia ei saatu vahvistettua.
- Epävarmat: Troldhaugen "puuhuvila" (rakennusmateriaali ei suoraan hakuotteessa); Fløibanen "yli kaksi miljoonaa matkaa vuonna 2018" (Wikipedia-ote 2 023 786); Fantoftin rakennusvuosi lähteissä 1150 tai 1170 → kirjoitettu "1100-luvulla"; Fantoftin Borgund-malli ja aita vain matkailusivuilta (thehiddennorth, Frommer's); Mariankirkon tornit "neliskulmaiset" (Wikipedia-ote: "two tall square towers"); tuomiokirkon tornin sijainti "länsipäässä" omaa tietoa – tarkista.
- Voorbode 1944: lähteissä sekä "hollantilainen laiva" että "saksalainen laiva" → kirjoitettu neutraalisti "räjähteitä lastattu laiva".
- Bryggen: aineiston lause nykytalojen iästä (neljäsosa vuoden 1702 jälkeen, "loput sitäkin nuorempia") on ristiriitainen, joten talojen ikää ei kerrottu; käytetty UNESCOn muotoilua jälleenrakennuksesta vanhan mallin mukaan.
- Fløyen ja Ulriken mainitsevat molemmat Vidden-reitin (Fløyen lyhyessä, Ulriken tekstissä) eri näkökulmista.
- Avaus 38 sanaa.

## Kysymykset (lisätty jälkikäteen)

Kenttä "kysymykset" lisätty 7.10. jokaiselle kohteelle (5 kpl, ≤ 60 mrk) sekä korjattu/ että luonnos/-tiedostoon; muut kentät ennallaan.

- Bryggen: Miksi hansakauppiaiden piti pysyä naimattomina? / Missä kauppiaat lämmittelivät, kun tuli oli kielletty? / Miksi Bryggenin puutalot ovat kallistuneet? / Milloin hansakauppiaat lopulta lähtivät Bergenistä? / Mitä Bryggenin vanhoissa taloissa on nykyään?
- Bergenhusin linnake: Kuka oli kuningas Haakon Haakoninpoika? / Miksi linnake rakennettiin juuri lahden suulle? / Ketä Rosenkrantzin tornin tyrmässä pidettiin? / Miksi satamassa räjähti laiva sodan aikana? / Mitä Haakonin salissa järjestetään nykyään?
- Fløyen: Mistä Fløyen on saanut nimensä? / Kuka istutti metsän vuoren paljaille rinteille? / Mitä peikoista kerrotaan norjalaisissa tarinoissa? / Miksi Bergenissä sataa niin paljon? / Mitä Fløyenilta näkee kirkkaalla säällä?
- Fløibanen: Kenen idea oli rakentaa rata vuorelle? / Miten kaksi vaunua pitävät toisensa tasapainossa? / Missä kohdassa vaunut ohittavat toisensa? / Miksi sininen vaunu on nimeltään Blåmann? / Millä pysäkeillä vaunu pysähtyy matkalla?
- Mariankirkko: Mikä kirkossa muuttui uskonpuhdistuksen jälkeen? / Ketkä lahjoittivat kirkolle saarnatuolin? / Mitä keskiaikaisessa alttarikaapissa kuvataan? / Miksi kirkon länsipäässä on kaksi tornia? / Pidetäänkö kirkossa yhä jumalanpalveluksia?
- Bergenin tuomiokirkko: Kuka oli Pyhä Olavi, jolle kirkko rakennettiin? / Mitä fransiskaanien luostarille tapahtui? / Kuinka monta kertaa kirkko on palanut? / Miksi tykinkuula jätettiin kirkon seinään? / Kuka oli Bergenin ensimmäinen luterilainen piispa?
- Fantoftin sauvakirkko: Miksi sitä kutsutaan sauvakirkoksi? / Miksi kirkon katoilla on lohikäärmeenpäitä? / Saatiinko kirkon tuhopolttaja koskaan kiinni? / Mikä on kirkon seinään upotettu toivekivi? / Voiko kirkkoon nykyään päästä sisälle?
- Troldhaugen: Mitä Grieg sävelsi järven rannan majassa? / Kuka oli Nina Grieg? / Miksi talo sai nimen peikkokukkula? / Miksi Grieg sävelsi mieluummin majassa kuin talossa? / Mitä konserttisalin lavan takana näkyy?
- Grieghallen: Miksi talon rakentaminen kesti niin kauan? / Kuka voitti Euroviisut Bergenissä? / Kuka johtaa Bergenin filharmonista orkesteria nyt? / Millaisia esityksiä talossa nähdään nykyään? / Miten pääsalin akustiikka on suunniteltu?
- Ulriken: Kuinka kauan köysiradalla kestää nousta huipulle? / Pääseekö huipulle kävellen ilman köysirataa? / Kuka rakensi portaat Ulrikenin rinteeseen? / Miksi huipulle rakennettiin televisiomasto? / Mitä huipulta näkee kirkkaalla säällä?
- Nykirken: Kuka arkkipiispa asui kivitalossa kirkon paikalla? / Näkyykö arkkipiispan talon raunioita yhä? / Kuka suunnitteli nykyisen kirkkorakennuksen? / Miksi laivan räjähdys tuhosi niin paljon? / Millainen paikka Nordnesin niemi on nykyään?

Oletusten tarkistus:
- Bryggen: hansakauppiaiden naimattomuusvaatimus ja tulenkielto taloissa (schøtstuer) vahvistettu haulla (en.wikipedia Hanseatic Museum and Schøtstuene).
- Fløyen: nimi tuuliviiristä (fløystang) vahvistettu, mutta lähteet sanovat "todennäköisesti". Metsän istutus 1800-luvulla (Bergens Skog- og Træplantningsselskab 1868) vahvistettu.
- Fantoft: "Saatiinko tuhopolttaja koskaan kiinni?" on tarkoituksella avoin: Vikernes vapautettiin juuri Fantoftin poltosta, tekijää ei ole tuomittu. Vastaajan pitää tietää tämä.
- Fløibanen: välipysäkit (Promsgate, Fjellveien, Skansemyren) ja ohituspaikka vahvistettu (floyen.no). Ulriken: sherpaportaat vahvistettu (visitbergen).
- Rosenkrantzin tornin tyrmä vahvistettu (bymuseet.no). Mariankirkon saarnatuolin lahjoittivat kauppiaat 1676, alttarikaappi pohjoissaksalainen 1400-luvulta (kirkon esite).
- Grieghallenin pitkä rakennusaika (rahat loppuivat, työ seisoi) vahvistettu (grieghallen.no). Troldsalenin lasiseinä lavan takana vahvistettu.
