# Ateena – huomiot tarkistajalle

- Isoisä: pohjan merkintä kertoo kahvilakeskustelusta Schliemannista eikä liity mihinkään pohjan kohteeseen, joten isoisää ei mainita (isoisa false kaikissa).
- LISÄSÄÄNTÖ A: Kallimarmaro alkaa "Marmoristadion Kallimarmaro…", Sýntagman aukio "Ateenan keskusaukio, Sýntagman aukio…" ja Pláka "Vanha kaupunginosa Pláka…" (tarkistimen huomiot "ei ala paikan nimellä" ovat tarkoituksellisia). Akropolis, Parthenon, Erekhtheion, Likavittos ja Herodes Atticus on jätetty alkuun vakiintuneina suomenkielisinä kirjoitusasuina – tarkista, ääntääkö kertoja ne suomeksi.
- Aineiston korjaus: aineiston mukaan Athena Niken kaiteen voitonjumalatar oli siivetön; lähteiden (Pausanias, visitgreece.gr) mukaan siivetön oli temppelin jumalankuva. Teksti noudattaa lähteitä.
- Erekhtheionin oliivipuu: aineiston mukaan sen istutti "kuningatar Sofia", verkkolähteen mukaan prinsessa Sofia vuonna 1952. Ristiriidan vuoksi tekstissä vain "istutettiin 1900-luvulla".
- Parthenon: "vajaassa kymmenessä vuodessa" = 447–438 eaa. "Pylväät kallistuvat sisäänpäin" ja "alusta kaartuu" perustuvat thecollector.com-lähteeseen; yleisesti tunnettua.
- Kallimarmaro: hopeamitali ja oliivinoksa 1896 vahvistettu aineistosta ja yleistiedosta (1896 Summer Olympics -artikkelia ei voitu avata, vain haku). Herodes Atticuksen aikainen marmoriasu 140-luvulla.
- Herodes Atticus "Rooman konsuli" (vuonna 143) – yleistieto, hakulähde ei näyttänyt tätä suoraan.
- Hadrianuksen kaari: vuosi "noin 131" (lähde: 131 tai 132).
- Akropolis-museo: "ylin kerros käännetty muuta taloa vinoon" ja "lasiseinäinen" perustuvat museon rakennussivuun (linjattu Parthenonin mukaan); tarkista sanamuoto.
- Sýntagma: vartio vaihtuu tasatunnein (aviewoncities.com). Metroaseman löydöt (archaeology-travel.com).
- Likavittos: "huipulta näkyy koko kaupunki merelle asti" – yleistieto.
- Lähde "kaanon:pelin-aineisto" jäi neljään väitteeseen (Athena Niken koko, Erekhtheionin karyatidien erot ja taru, evzonien asu, Tuulien tornin vesikellon vesi).

## Kysymykset (lisätty jälkikäteen)

Kenttä "kysymykset" lisätty 7.10. jokaiselle kohteelle (5 kpl, ≤ 60 mrk) sekä korjattu/ että luonnos/-tiedostoon; muut kentät ennallaan.

- Akropolis: Miksi Akropolis rakennettiin juuri tälle kalliolle? / Mitä Manolis Glezokselle tapahtui myöhemmin? / Millainen oli Akropoliin porttirakennus Propylaia? / Miksi Akropoliille rakennettiin hissi? / Kuinka monta vierailijaa kalliolla käy päivässä?
- Parthenon: Millainen oli Athenen jumalankuva temppelissä? / Mistä Parthenonin marmori tuotiin? / Millaisiksi Parthenon alun perin maalattiin? / Miksi Kreikka vaatii veistoksia takaisin Lontoosta? / Miksi Parthenonia on korjattu vuosikymmeniä?
- Antiikin agora: Miksi ateenalaiset tuomitsivat Sokrateen kuolemaan? / Mitä torilla myytiin antiikin aikana? / Miten ateenalaiset arpoivat valamiehensä? / Mitä agoran paikalla oli ennen kaivauksia? / Minne agoran halki kulkenut juhlatie johti?
- Olympoksen Zeuksen temppeli: Kuka oli tyranni Peisistratos? / Millainen Zeuksen patsas temppelissä oli? / Mihin temppelin kadonneet pylväät joutuivat? / Miksi pylväät ovat korinttilaisia eikä doorilaisia? / Miksi Hadrianus halusi saattaa temppelin valmiiksi?
- Kallimarmaro (Panathinaïkó-stadion): Mitä Spyridon Louisille tapahtui kisojen jälkeen? / Kuka oli lahjoittaja Georgios Averoff? / Mitä stadionilla tehtiin antiikin aikana? / Miksi stadionin radassa on niin jyrkät kaarteet? / Saako stadionin radalla juosta nykyään?
- Erekhtheion: Kuka oli tarujen kuningas Erekhtheus? / Miksi temppeli on niin epäsymmetrinen? / Missä Poseidonin kolmikärjen jäljet näkyvät? / Mikä käärme temppelissä tarun mukaan asui? / Miksi alkuperäiset karyatidit siirrettiin museoon?
- Akropolis-museo: Miksi museon rakentaminen herätti kiistaa? / Keitä museon arkaaiset neitopatsaat esittävät? / Millaista elämää museon alla olleessa kylässä oli? / Miten museo suojaa veistokset maanjäristyksiltä? / Mitä museon ravintolan terassilta näkee?
- Hefaistoksen temppeli: Millainen jumala tulen ja sepäntaidon Hefaistos oli? / Keitä temppeliin haudattiin kirkkokaudella? / Millainen kuningas Otto oli kreikkalaisille? / Pääseekö Hefaistoksen temppelin sisälle? / Miksi Theseusta pidettiin Ateenan sankarina?
- Sýntagman aukio: Mistä Sýntagman aukio on saanut nimensä? / Miten evzonit valitaan kaartiin? / Kuinka painavat evzonien tupsukengät ovat? / Miksi aukiolla järjestetään niin usein mielenosoituksia? / Mikä puutarha parlamenttitalon takana on?
- Likavittos: Mistä Likavittos on saanut nimensä? / Miksi köysirata kulkee kallion sisällä tunnelissa? / Mitä huipun kappelilla tapahtuu pääsiäisyönä? / Keitä Likavittoksen teatterissa on esiintynyt? / Kuka istutti männyt kukkulan rinteille?
- Pláka: Miksi Plákaa kutsutaan jumalten naapurustoksi? / Asuuko Anafiotikan taloissa yhä ihmisiä? / Mitä ottomaanien ajalta Plákassa on jäljellä? / Miksi Plákan kujilla ei juuri näe autoja? / Miksi Anafiotikan talot muistuttavat saaren kylää?
- Herodes Atticuksen odeion: Oliko odeionilla alun perin katto? / Miksi herulit hyökkäsivät Ateenaan? / Keitä odeionin lavalla on esiintynyt Callasin jälkeen? / Miten ääni kantaa katsomoon ilman mikrofoneja? / Pääseekö odeioniin muulloin kuin esitykseen?
- Tuulien torni: Keitä kahdeksan tuulenjumalaa ovat? / Kuka oli tähtitieteilijä Andronikos Kyrrhoslainen? / Mitä tornissa tehtiin ottomaanien aikana? / Miksi ateenalaiset halusivat tietää tuulen suunnan? / Mikä oli roomalainen tori tornin vieressä?
- Hadrianuksen kaari: Miksi keisari Hadrianus rakasti Ateenaa? / Millainen oli keisarin uusi kaupunginosa? / Mitä muita rakennuksia Hadrianus Ateenaan rakensi? / Miten liikenteen saasteet ovat kuluttaneet kaarta? / Miten kaari on säilynyt lähes ehjänä?
- Dionysoksen teatteri: Millaisia naamioita näyttelijät käyttivät? / Miksi kaikki näyttelijät olivat miehiä? / Mitä eturivin kunniaistuimiin on kaiverrettu? / Mitä teatterissa tehtiin roomalaisten aikana? / Esitetäänkö teatterissa yhä näytelmiä?

Oletusten tarkistus:
- Akropolis-museon maanjäristyseristys (kitkaheiluri-laakerit) vahvistettu haulla.
- Kallimarmaro: aamulenkit radalla sallittu (7.30–9) useiden matkailulähteiden mukaan; jyrkät kaarteet vahvistettu.
- Hefaistoksen temppeliin haudattiin 1800-luvun alussa protestantteja ja filhelleenejä: vahvistettu.
- Dionysoksen teatterin kunniaistuimien kaiverretut nimet/arvonimet vahvistettu. Tuulien torni dervissien tekkenä vahvistettu.
- Epävarmempia: "Oliko odeionilla alun perin katto?" (antiikin lähteiden mukaan setripuukatto, kysymys on muotoiltu avoimeksi); Likavittoksen mäntyjen istutus ja pääsiäisyön kulkue kappelilla yleistietoa, ei erikseen haettu.
