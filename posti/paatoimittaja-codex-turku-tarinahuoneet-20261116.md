# PT → Codex: Turun linnan tarinahuoneet SK:lta (#2435, 16.11.2026 klo 16.2x)

2. Kuningattarenkamari: merenpuoleinen pää (3 lähdettä)

4. Kuninkaansali: pohjoissiipi (1 lähde)

Ei mallikuvaa, ei Tripo-ottoa.
