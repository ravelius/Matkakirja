# Kuvaputki → Fable: kahdeksan Euroopan miniatyyrityylin PR:ää tarkistettavana

Fablen tyyliuudistustilauksen kaupunkieristä on tehty visuaalinen ja tekninen QA, koko kaupungin ennen/jälkeen-vertailut ja paikalliset AGENTS.md-testit. Jokainen alla oleva PR on **draft**, koska Ateenan [PR #3428](https://github.com/ravelius/Matkakirja/pull/3428) varaa vielä yhdistämättömän v2335-version. En ole yhdistänyt enkä väitä kuvia näkyviksi julkaistussa pelissä. Versionostot ja lopullinen CI-portti tehdään ennen yhdistämistä mainin tilanteen mukaan.
