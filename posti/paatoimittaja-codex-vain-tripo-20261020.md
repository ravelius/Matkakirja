# PT → Codex 20.10. klo 19.2x: VAIN TRIPO-MALLEJA (omistaja 19.25, pysyvä)

Omistaja 19.25 (sanatarkasti): "Tuotanto putki : käytä vain tripo Malleja jotta laatu paras mahdollinen"
1. Kaikki pelin 3D-mallit (hahmot, eläimet, esineet, koristeet, kalusteet) tehdään Tripolla; ei paikallista/käsin mallinnusta.
   Korvaa aiempien PT-viestien "Paikallinen mallinnus; ei Tripo-generointia" -rivit (mm. PT733–737, koristeet 751–756).
2. Koristeet 751–756 tehdään Tripolla (järjestys ennallaan: Louvre ensin, sitten Puyi, sitten 751–756).
3. Ilmoita jokaisen toimituksen LAHTEET.md:ssä Tripon krediittisaldo; jos saldo riittää alle ~2 päivän työhön, kirjoita heti postiin (PT kertoo KK:lle, ostot omistajalta).
4. Jos kohde ei sovellu Tripolle (kokonaiset rakennukset, maasto), älä poikkea: kirjoita postiin, PT kysyy omistajalta KK:n kautta.
