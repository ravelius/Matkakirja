SUUNTIEN KIINNITYS (rakennuksesta, koska geotagit = linnan keskipiste 48.6735 N 26.5629 E, esim. ruutujen 3 ja 5 "Camera location" on sama piste):
- Ruudun 3 ilmakuvasta luettu linnan pitkä muuri, tornijärjestys vasemmalta oikealle: (a) matala pyöreä aumakattoinen kulmatorni, (b) valkoinen pyöreä torni aumakatolla, (c) tumma teräväkatto, (d) teräväkatto tiilivyöllä, (e) mänty + matala muuri, (f) toinen tiilivyöllä varustettu teräväkatto, (g) pieni aumakattotorni, (h) neliskulmainen aumakattoinen torni oikeassa päässä; Linnansilta jatkuu kuvan oikeassa reunassa taustalla kohti vanhaakaupunkia. Vanhakaupunki (sinikupolinen kirkko) on linnan takana. Aurinko laskee kuvan vasemmalla (taivas oranssi vasemmalla) = länsi vasemmalla => kamera etelässä katsoo pohjoiseen: ruutu 3 = ETELÄ (vino ilma). Päällekkäin aiemman arvion S/SSE kanssa; vahvistuu.
- Ruutu 2 (P1840618, 9.5.2021 klo 20.06): näkyy järjestys aumakattoinen torni, valkoinen pyöreä torni, teräväkatto, tiilivyöllinen teräväkatto = ruudun 3 vasen pää (a, b, c, d) => LÄNSIPÄÄ/WSW. Iltaaurinko (WNW, ~285 astetta) valaisee seinän edestä (kamera länsipuolella); ruoho ja ilmapallo. Aiempi arvio S/SW tarkentuu W/WSW.
- Ruutu 5 (UUSI, Posterrr, 30.8.2020 klo 19.37): iso pyöreä aumakattotorni edessä, ohut tiilivyöllinen teräväkatto sen takana vasemmalla, pyöreä torni + teräväkatto oikealla; aurinko WNW ~280 astetta valaisee tornin etupuolen ja jättää oikean muurin varjoon => kamera SW-W (kulma 190-280 astetta). Kuva on ylhäältä rinteeltä (ei ilmakuva). ARVIO WSW/SW, lähempää ja korkeammalta kuin ruutu 2. Tornien tunnistus (sama torni kuin ruudun 3 vasemman pään (a) tai (b)) on EPÄVARMA.
- Ruutu 1 (001, Petishkin, 8.9.2012 klo 08.25): vasemmalla neliskulmainen aumakattoinen torni (portti-/kulmapää), oikealla kaksi korkeaa tiilivyöllistä teräväkattoa, Linnansilta tulee oikealta alhaalta portille. Tornijärjestys on ruudun 3 peilikuva (neliskulmainen aumakatto + pieni aumakatto + teräväkatto + kaksi tiilivyöllistä teräväkattoa) => kuva 001 näyttää samaa muuria vastakkaiselta puolelta eli POHJOIS-/KOILLISPUOLELTA vinosti idästä (portti- ja siltapääty); aamuaurinko ESE valaisee kameraa kohti => kamera idässä/koillisessa. Merkintä NE/E. TÄMÄ on lähimpänä KK:n pyytämää pohjoista sivua (muuri näkyy ~60 % leveydestä, vinosti).
- Ruutu 4 (Castle-02, Nomad0212): tornijärjestys vasemmalta: raunio + pieni teräväkatto, valkoinen pyöreä aumakattotorni, tiilivyöllinen teräväkatto, kaksi pientä pyöreää tornia; iltapäiväaurinko (15.02, lounaassa) valaisee kameraa kohti => kamera S/SW kanjonin toiselta rannalta. EPÄVARMA ja lähes sama puoli kuin ruutu 3 (ero: maa vs ilma). Rinteellä valkoisia laikkuja, jotka voivat olla huurretta tai lunta (sääntö 3) => kevennetty, KK harkitsee; 1334 px filmiskannaus.
