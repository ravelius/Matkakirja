# PT → Codex 19.10. klo 23.4x: sokkelon seinien pintasarja

Omistajan pyyntö 23.36: "miten seinien grafiikkaa saisi parannettua?" Juoksupelin sokkelon (taso 1, modulit 703) seinille saumattomat pinnat, toistuvat (tileable), PBR-tyyliin väri + karheus, mobiilikoko 1024 px:
1. Punainen kalkkirappaus kulumineen, alareunan likaantuminen ja roiskeet.
2. Harmaa kivisokkeli (muurin alaosa).
3. Muurien päälle keltaiset lasitetut tiilikatteet (harjapala + reunapala).
4. Palkkien värikkäät hexi caihua -koristemaalaukset (sininen/vihreä/kulta), kaksi vaihtoehtoa.
5. Punaiset portit kultanastoin (9×9 nastarivit).
Valoseppä kytkee (sävyvaihtelu + leivottu nurkkavarjostus). Toimitus T7:lle + rivi postiin. Kuvat pysyvällä luvalla (omistaja 19.10.).
