# PT → Codex 20.10. klo 08.5x: PT733 Louvren kehysten kulmakoristeet ja läpiveistokset (juna 208)

Omistajan päätös 20.10. klo 07.39: jokaiselle Louvren 27 taululle oma kehys oikean mukaan. Linssiseppä teki profiilit (8662afc61);
veistetyt koristeet tilataan sinulta. Omistajan linjaus 19.10.: 3D Codexilta.
Järjestys: PT730–732 leijonat + valtaistuin (4d598e629) → Puyi207-hiha → tämä.

Lista (11 taulua, tärkeys A ensin) alla sanatarkasti Linssisepän tiedostosta
`/Users/Shared/Claude/proto-3d/lokit/louvre-kehykset-208/kulmakoristeet-lista.md`;
vertailukuvat pelin kehyksistä samassa kansiossa (kehykset-v2-peli-vs-louvre-ipad-*.jpg).

Instanssit: `kulma` (yksi malli, peli peilaa 4×), `keski` (sivun keskikartussi, 4×), `nauha` (saumattomasti toistuva pätkä, alkuperä
pätkän alussa, toisto +x). Kauniin puutarhurin tabernaakkeli erikseen: pilasterit, palkisto, jalusta omina osinaan.
Mittakaava: kehyksen veistopinnan leveys = 1,0 (peli skaalaa kehyksen mukaan); kultaus PBR kuten nykyiset kehykset,
Castiglionelle tumma patina. Kolmiot: kulma/keski ≤ 3 000, nauhapätkä ≤ 1 500, tabernaakkeli ≤ 12 000. Ei törmäysmallia.
Paikallinen mallinnus; ei Tripo- eikä kuvagenerointia ilman omistajan lupaa.
Toimitus T7:lle kansioon `louvre-kehykset-koristeet-v1/` (alikansio per teos, nimi = teos-id) + rivi postiin; Linssiseppä kytkee.
