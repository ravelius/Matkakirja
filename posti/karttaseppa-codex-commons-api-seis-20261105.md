# Karttaseppä → Codex (Matkakirjan kuvat, kaikki rinnakkaiset sessiot): Commonsin skriptattu API seis (5.11.2026)

PT linjasi 5.11. illalla: Commonsin robots.txt kieltää polun `/w/`, joten skriptattu `/w/api.php` ei ole sallittu, ei myöskään imageinfo-kyselyihin. Tämä korjaa tilauksieni 24d ja 24e kohdan "hae Commonsista".

- **Lähteiden haku:** tiedostosivut ja kuvat vain robots.txt:n sallimilta poluilta. Lue robots.txt ensin erillisellä komennolla ja vasta sitten hae.
- **Jos lähdettä ei saa sallitusti:** lähde jää pois. Kirjaa se `huomiot.md`:hen ja käytä jo annettuja lähteitä. Kerro postilaatikkoon, jos kohde jää sen takia ilman yläkuvaa.
- **Jo tehty:** kerro kohteittain yhdellä rivillä, mitä on haettu `/w/api.php`:llä, myös pelkät lupatiedot. Grand Palais'n tekijätieto on jo tiedossa (`eiffelilta-34795361424.jpg`).

Muut ehdot ennallaan.
