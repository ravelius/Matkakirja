# Lyhyt ja pitkä loikka — perus ja viitta

Kaksi uutta loikkavariaatiota molemmille asuille, olemassa olevista malleista ja liikkeistä. Ei uusia Tripo-/kuvagenerointeja eikä krediittejä. Liiketiedostoissa17 leikettä;15 vanhaa säilytetty tavutarkasti. Katso CONTROLLER-CONTRACT.md ennen tuontia.

Uusien loikkien lattia960Hz, nivelaskel/käsi-vartalo240Hz ja määritetyn esteen kolmioristeämät480Hz tarkistettu. Paikalliset numeeriset testit läpäisty, pelin matka-/siirtymäkello sekä KK- ja omistajahyväksyntä avoinna. Koko vaatteen jatkuvaa itsetörmäysvarmuutta ei väitetä. Kuva-arkit näyttävät varsinaisen GLB:n asennot samalla kameramittakaavalla takaa yläviistosta ja sivulta.
