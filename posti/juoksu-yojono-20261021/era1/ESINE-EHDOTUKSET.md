# Rikkoutuvat esineet — 8 ehdotusta

Omistajan valinta ja mallinnuslupa ovat avoinna. Kuva näyttää ehjän esineen; alla oleva liike/hajoaminen on ehdotus.

| Esine | Yksi ehdotusrivi | Suunniteltu liike |
|---|---|---|
| Matala saviruukku | Kevyt arkinen ruukku; osuma rikkoo muutamaan tylppään pelipalaseen, ei terävien sirujen lähikuvaa. | Staattinen ennen osumaa; kaatuminen/hajoaminen vain myöhemmän omistajavalinnan jälkeen |
| Bambukori | Kori kaatuu ja painuu kasaan; koristeellista pölyä, ei arvosisältöä. | Staattinen ennen osumaa; kaatuminen/hajoaminen vain myöhemmän omistajavalinnan jälkeen |
| Paperilyhty | Sammumaton vaaraton pelilyhty ilman tulta; osuma painaa paperirungon kasaan. | Staattinen ennen osumaa; kaatuminen/hajoaminen vain myöhemmän omistajavalinnan jälkeen |
| Posliinivati | Arkinen sinivalkoinen vati; hajoaminen muutamaan selkeään peliosaan. | Staattinen ennen osumaa; kaatuminen/hajoaminen vain myöhemmän omistajavalinnan jälkeen |
| Puulaatikko | Kevyt kanneton laatikko; sivulaudat irtoavat osumasta. | Staattinen ennen osumaa; kaatuminen/hajoaminen vain myöhemmän omistajavalinnan jälkeen |
| Lakkatarjotin | Tarjotin putoaa ja halkeaa; pieni poimittava koriste voi vapautua vasta erillisen pelipäätöksen jälkeen. | Staattinen ennen osumaa; kaatuminen/hajoaminen vain myöhemmän omistajavalinnan jälkeen |
| Bambuteline | Matala tarviketeline kaatuu; osat liikkuvat kevyesti, ei piikkejä. | Staattinen ennen osumaa; kaatuminen/hajoaminen vain myöhemmän omistajavalinnan jälkeen |
| Kangaspussi | Pussi rojahtaa ja avautuu; kangasta/pölyä, ei ruokahävikkiä korostavaa näkymää. | Staattinen ennen osumaa; kaatuminen/hajoaminen vain myöhemmän omistajavalinnan jälkeen |
