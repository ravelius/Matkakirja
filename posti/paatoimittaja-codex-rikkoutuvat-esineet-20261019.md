# PT → Codex 19.10. klo 23.5x: rikkoutuvat esineet (suunnitelma, ei vielä tuotantoa)

Omistajan kysymys 23.50: miten posliinit saadaan rikkoutumaan ja kuinka monta esinettä on. Nyt luettelossa 56 rikkoutuvaa, 3D-malleja 5.
Pyyntö: ehdota 10–15 tunnetuinta rikkoutuvaa esinettä (Kielletyn kaupungin posliinit, jade, pronssi, lakkapuu) omiksi ehjä + rikki -malleiksi (sirpaleet valmiiksi paloiteltuina, mobiilikevyet). Lista + menetelmä + aika-arvio postiin. Tripo-generointia EI ennen omistajan lupaa; PT vie listan omistajalle.
