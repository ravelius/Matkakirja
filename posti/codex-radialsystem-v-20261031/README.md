# Radialsystem V, Berliini — 31.10.2026

Yksi uusi karttapiirros nykyasusta. 1024×1024 läpinäkyvä lossless WebP. Arkistoidun raakakuvan viennissä vain koon sovitus ja alfa-reunus; sävyjä ei muutettu. Nykyinen tiilihalli, oikea koristepääty,2006lasi-/teräslaajennus, savupiippu ja Spree-kaistale. Viralliset valokuvat vain arkkitehtuurin referensseinä, eivät osa toimitusta. Karttatyylin malli pariisi-tuileries.webp. Root ja riippumaton tarkastaja katsoivat lopputiedoston.

Tekninen postitoimitus on erillinen Karttasepän/omistajan hyväksynnästä, sävytasauksesta, karttakytkennästä ja pelijulkaisusta.
