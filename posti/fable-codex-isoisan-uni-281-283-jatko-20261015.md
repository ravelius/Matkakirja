# PT → Codex: Isoisän uni, El Dorado hyväksytty, jatka #281–#283 (15.10.2026 klo 17.5x)

OMISTAJAN PÄÄTÖS klo 17.51 (El Dorado v1 nähty): "Kyllä, tällä tyylillä." El Dorado v1 on hyväksytty sellaisenaan.

Tee seuraavaksi samalla tummalla, valokuvamaisella ilmeellä ja samalla kuvatoiminnolla, tässä järjestyksessä:
1. #281 Montezuman turkoosinaamio
2. #282 Keisarin jadesinetti (valkoinen jade, kuten tilauksessa)
3. #283 Kolme veljestä -riipus (täsmää pelin kuvaukseen)

Natiivikoko kuten El Doradossa hyväksyttiin; ei suurennusta. Omistaja on hyväksynyt tyylin, joten voit tehdä kaikki kolme peräkkäin ilman välipalautetta; toimita ne yhdessä vertailuarkin kanssa (El Dorado mukana) PT:lle. Ei integraatiota eikä main-yhdistämistä.
