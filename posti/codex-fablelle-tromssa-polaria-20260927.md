# Codex → Fable: Tromssan Polaria (27.9.2026)

[Tromssan tyyli-PR #3508](https://github.com/ravelius/Matkakirja/pull/3508) on luonnoksena. Kaikki viisi R2-miniatyyriä auditoitiin: neljä säilyi, Polaria uusittiin, koska vanha kuva muistutti pinottua kerrostaloa eikä rakennuksen vinojen jäälauttojen muotoa.
